# v0.5.0.28 release notes

## Summary

v0.5.0.28 is a presentation-only localization correctness release. It fixes
real-device English leaks in calendar, exercise information, Plan, coaching,
fatigue analysis, and current-performance surfaces without changing locale
selection, persistence, metadata, or calculations.

## Corrected production paths

- Calendar month and weekday labels now use `YearMonth` and `DayOfWeek` with
  the active app locale (`Aug 2026`, Monday through Sunday).
- Added stableKey-based English overlays for all 257 built-in/history exercise
  descriptions. Custom descriptions remain verbatim.
- Added stable-identity English overlays for all 12 seeded program names. User
  program names remain verbatim.
- Sleep, RPE, joint/tendon, and court-duration coaching states now carry stable
  message codes and are formatted by localized Android resources.
- The current-performance card uses the approved `Posterior median` identity,
  coherent control casing, and full intrinsic-width key-lift chips.
- Fatigue analysis uses `Overview`, `Details`, `High-load axes`, and
  `Lower-load axes`; the former generic machine translations are not used on
  those controls.
- Bottom navigation and reported Plan/Exercise controls use product-role
  capitalization.

## Audit hardening

The deterministic audit now includes Android resources, Kotlin UI origins,
built-in exercise descriptions, seeded program names, custom-content
passthrough, semantic date paths, semantic coaching codes, and statistical
model labels. It records approved, generated, passthrough, canonical,
internal-debug, and unexplained states separately. The final unexplained
production-leak count is zero and current-baseline `CHECK_REQUIRED` remains
zero.

## Technical detail decision

The expandable persistent-strength lifecycle, observation, provenance, and
numerical-diagnostic fields remain user-facing technical detail. They explain
the analysis lifecycle and are localized around exact technical codes. No
reviewed line was removed as accidental debug output.
