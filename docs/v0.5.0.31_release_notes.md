# v0.5.0.31 release notes

## Summary

v0.5.0.31 fixes the remaining Korean text visible in the English exercise and
initial-profile screens.

## Changes

- Built-in exercise list summaries now use localized canonical category,
  equipment, and a localized display-only recording-method label instead of
  untranslated legacy mode text.
- Built-in exercise detail summaries now use localized canonical muscle values
  instead of untranslated legacy detail strings.
- Initial-profile recovery slider titles are localized before their numeric
  value is appended.
- User-created exercise text remains unchanged and is not machine-translated.

## Preserved boundaries

- Stored exercise metadata, stable keys, backup/restore data, Room schema,
  analysis calculations, ProgramBuilder, and user records are unchanged.
- Korean presentation is unchanged.
- `app/outputs/` remains user-owned and excluded.
