# WhatYouGottaDo 0.5.0.22

## Cause

Bundled exercise metadata was split across a review workbook, seed parsing,
runtime CSVs, role assets, and inference-heavy compatibility code. That made
the human-editable authority and runtime result capable of drifting.

## Changes

- Added the canonical authoring workbook and deterministic Python validator,
  exporter, check mode, manifest, and tests.
- Added strict `canonical_v1` assets and
  `CanonicalExerciseMetadataRepository` for exact stableKey joins.
- Moved production seed, runtime metadata, role/capability, timing, equipment,
  movement, muscle, OFI, badminton, recovery, progression, and strength-proxy
  reads to the canonical repository.
- Kept reviewed tissue runtime assets separate and numerically unchanged.
- Preserved legacy/import inference only in explicit compatibility paths.

## Approved metadata decisions

1. `KEEP_CANONICAL` and `PROPOSED_USER_APPROVED` now live in
   `identityDecisionStatus`, not `mappingConfidence`.
2. All 16 history-only generic identities remain readable but inactive and
   non-selectable.
3. Active single-leg RDL and calf-raise slot capabilities moved to the
   approved concrete variants; historical generic stableKeys were not
   inferred or rewritten.
4. `ex_8824026f` is `STRENGTH` plus `ACCESSORY_SLOT`, not plyometric.
5. Effective `defaultRestSeconds` values were materialized for all 241
   selectable identities without changing prescription behavior.

## Safety and compatibility

Room remains schema 27. Backup format and restore schema are unchanged.
Workout history, saved programs, custom exercises, user IDs, and historical
stableKeys are not rewritten. Existing saved programs remain readable; fresh
built-in seeds with an unresolved or history-only item are skipped rather than
partially inserted.

Canonical bundled scientific metadata cannot be replaced by ordinary runtime
overrides. Existing custom-exercise persistence and user-editable runtime
fields such as program slot remain effective; canonical lineage, tissue/OFI,
recovery, and other protected relations stay authoritative.

## Validation

The workbook validator, deterministic exporter/check mode, and five Python
tests passed. Focused metadata/ProgramBuilder/backup/analysis/tissue tests and
all 1,144 debug unit tests passed. `compileDebugKotlin`,
`compileDebugAndroidTestKotlin`, and `assembleDebug` passed. Protocol
validation passed for 8 families and 33 protocols.

## Deferred

Relationship correctness was not fully adjudicated. The workbook and manifest
therefore retain `NOT_ADJUDICATED`. Research drafts remain non-runtime, and
deferred review rows are not promoted into production assets.

## Rollback

Revert this application commit. No Room downgrade or user-data rewrite is
required because the schema stayed at 27 and the cutover introduced no
destructive migration or generic-to-variant history rewrite.
