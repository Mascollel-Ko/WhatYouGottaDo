# v0.5.0.13 Release Notes

## Purpose

v0.5.0.13 removes hidden fatigue/readiness mutation from saved training-program
application.

## Exact Application Contract

- `TrainingViewModel.applyProgram`, `TrainingRepository.applyProgramToDates`
  and `ProgramPlanService.applyProgramToDates` no longer accept or forward a
  `TrainingGateSnapshot`.
- Every saved program item is resolved through
  `ProgramSetPrescriptionResolver`.
- Legacy scalar items and authoritative child-set items follow the same path.
- Every saved exercise and set is inserted exactly as an unconfirmed workout
  plan for today or a future date.
- Fatigue, readiness, check-in, OFI and connective-tissue analysis cannot
  remove, replace, reduce or scale a saved program during application.

## Preserved Behavior

- Append and overwrite semantics are unchanged.
- Overwrite removes only existing unconfirmed planned rows in the target range.
- Confirmed history, date mapping, duration, exercise ordering and set ordering
  are unchanged.
- Fatigue/readiness analysis, warnings and program-generation policies remain
  available as advisory or generation-time behavior.
- Room remains 26. Backup format remains 9, restore CSV schema remains 8 and
  program backup schema remains 2.
