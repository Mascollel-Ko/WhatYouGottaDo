## Scope

Phase 2A changes documentation, deterministic audit generation, generated audit
artifacts, and tests only. It does not change production Kotlin, current analysis
or program output, Room, backup/restore, or the immutable Phase 0/1 baseline.

The supplied fixed-property strategy v2.2 replaces v2.1. It separates fixed
exercise metadata from records and computed results, treats program timing as a
fixed parameter, and separates implementation risk paths from proven errors.

## Semantic mapping corrections

- `defaultRestSeconds` is `FIXED_PROGRAM_PARAMETER / PROGRAM_GENERATION /
  ExerciseProgramTimingProfile / DIRECT_COPY / SEMANTICALLY_REVIEWED`. It is the
  per-exercise default used by automatic session-time budgeting, not a generated
  program item's final `restSeconds` prescription.
- `activityKind` remains `LEGACY_COMPATIBILITY_READONLY /
  NON_METADATA_LEGACY_COMPATIBILITY / NONE / UNRESOLVED`. It is not promoted to
  movement/anatomy metadata.
- `progressMetricType` remains read-only compatibility with target relation
  `NONE`; replacement remains outside canonical metadata after parity and
  rollback gates.
- `analysisEligibility` has exact consumer-specific candidate destinations for
  OFI, badminton transfer, strength performance, program planning/block policy,
  presentation, and provenance. Unknown consumers remain explicitly unresolved.
  No row is approved for REVIEWED_V1.

## Risk and error separation

The former 20-row issue ledger described code paths, not 20 proven exercise
errors. It is replaced by:

- `metadata_legacy_inference_risk_paths.*`: one row per implementation path;
- `metadata_inference_stablekey_impact.*`: every path/stableKey pair;
- `confirmed_metadata_errors.*`: only independently proven errors.

No confirmed error was proven, so the confirmed-error CSV is a valid header-only
artifact and the Markdown count is zero. No production classification was fixed.
