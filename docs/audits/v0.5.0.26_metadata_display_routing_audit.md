## Contract defects and repair

The baseline generated field-display contract contained 109 fields:

- catalogue-routed fields: 96;
- catalogue-routed fields with an unknown `displayDomain`: 90;
- invalid typed `valueKind` / `localizationMode` combinations: 18;
- explicit hybrid catalogue/user-text fields: 0.

The repaired source registry now yields:

- catalogue-routed fields: 69;
- catalogue-routed fields with an unknown `displayDomain`: 0;
- invalid typed `valueKind` / `localizationMode` combinations: 0;
- explicit hybrid catalogue/user-text fields: 3;
- explicit non-display fields: 18.

`exercise.category`, `exercise.detail1`, and `exercise.detail2` use exact catalogue lookup
with user-text passthrough. `exercise.description` remains ordinary free text.

`exercise.archivedAt` retains its existing semantic `DURATION` value kind so the semantic
revision does not change, but its presentation contract is `NEVER_DISPLAY` and
`NON_DISPLAY_IDENTIFIER`; an epoch value cannot be rendered as elapsed duration.

Fields without an approved catalogue domain and without a current user-facing presentation
path are explicitly non-display rather than receiving invented translations.
