# v0.5.0.36 Calculator Internal Metadata Semantic Parsing Debt

This inventory is intentionally separate from exercise-name semantic authority. None of these items uses an exercise display name as authority. They parse explicit metadata or protocol fields and remain valid production behavior for this release.

| Area | Current parser/logic | Authority input | Follow-up direction |
|---|---|---|---|
| `ExerciseMetadataAdapter` | Delimited token normalization and derived stress tags | Explicit runtime metadata fields | Replace derived tags with generated typed relations when every consumer has migrated. |
| `ExerciseMetadataMapper` | Muscle/stability/balance token membership | Canonical muscle and movement metadata | Continue typed-relation migration; retain current formulas until parity is demonstrated. |
| `DailyFatigueCalculator` / `FatigueMath` | Recovery profile and stress-level enum/token parsing | Explicit fatigue metadata | Move remaining string enums to typed generated assets without changing OFI formulas. |
| `CourtDurationRecoveryAnalyzer` | Sport-context and transfer token parsing | Explicit runtime sport metadata | Replace with typed sport-session relation after parity coverage exists. |
| `CommonStrengthMetrics` / `CommonTaxonomyMetrics` | Movement/taxonomy key prefix matching | Canonical structured movement keys | Replace prefix families with typed family relations in a separate semantic phase. |
| `StrengthPerformanceRegistry` | Reviewed proxy-factor IDs and loading keys | Canonical strength registry assets | Preserve current posterior/proxy authority; consider typed factor IDs only with migration parity. |
| Tissue parsers and validators | Protocol CSV enum/list parsing | Canonical connective-tissue protocol assets | Keep at controlled asset boundary; no runtime exercise-name fallback is permitted. |
| Time-series pipeline | Metric keys, lifecycle ranges, diagnostic codes | Canonical metric/protocol identifiers | Keep separate from exercise identity; migrate only when registry types cover all keys. |

Excluded from this debt category:

- UI/search/localization string operations.
- CSV parsing that only transports display text.
- Explicit historical stableKey compatibility maps.
- ProgramBuilder planning/scoring internals, whose exact candidate admission remains governed by `ProgramCandidateAuthority`.

The broader discovery source remains `metadata_parsing_inference_audit.md` and its CSV companion. This file records the reviewed calculator-internal subset after the v0.5.0.36 exercise-name cleanup.
