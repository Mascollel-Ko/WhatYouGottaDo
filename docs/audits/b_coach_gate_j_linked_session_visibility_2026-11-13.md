# B-Coach Gate J: 계획 연결 가시화 및 기록 날짜 연동 (2026-11-13)

## 사용자 관찰과 원인
새 B 프로그램의 4주 동일 스쿼트는 모두 중량 미설정으로 생성된다. 기존 ProgressionTrackInference.sameTrack()는 이 경우 REVIEW 정책을 생성하며, REVIEW끼리는 자동 그룹화를 금지한다. 그 결과 Gate I가 (같은 적용 프로그램, 같은 trackId, 다음 sequence)로 찾는 다음 연결 스쿼트가 없었다. CI 단위 테스트는 생성부터 적용까지의 통합 경로를 검증하지 못했다.

## 구현
- B 생성 결과에 bCoachSessionAutoLinkSchema=uncalibrated-v1 저장. 원판 크기의 존재와는 독립적으로 프로그램 연결 의도를 남긴다.
- 저장 및 달력 적용 시 ProgramProgressionService.author()에서 동일한 운동 stableKey, 3×6 등 동일 세트/반복, 스타일·변형·훈련 슬롯·강도·역할이 같은 **AUTO REVIEW + 무중량** 발생만 하나의 trackId로 연결한다. 같은 날짜의 서로 다른 발생은 자동 병합하지 않는다.
- 명시적인 EXISTING, SEPARATE, OFF 및 다르게 구성된 HEAVY/VOLUME은 우회하지 않는다. B가 아닌 일반 무중량 계획은 기존 REVIEW 분리 규칙을 유지한다.
- 계획 상세와 프로그램 생성 미리보기의 진행 세션 줄 바로 아래에 '연결된 진행 세션 1/4 · 이전 … · 다음 …'을 표시하며, 연결 하나뿐이라면 설정 버튼을 눌러 추가 연결을 하라고 안내한다.
- 기록 화면에는 적용된 프로그램의 같은 applicationId+sourceProgramStableKey+trackId, sequence를 통해 **직전 / 다음 연결 운동의 실제 저장된 날짜**를 표시한다. 날짜를 옮기거나 밀면 Room Flow에서 즉시 다시 계산한다. 달력 7일 간격으로 추정하지 않는다.
- 처음부터 중량이 비어 있는 프로그램에는 여전히 1주차 사용자 직접 입력이 필요하다. 다음 스쿼트의 중량 수정은 Gate I의 e1RM·RPE 기반 로직이 담당한다. **데드리프트·다른 근력운동에 검증된 자동 처방식을 새로 구현한 것은 아니다.**

## 테스트
- B 새 프로그램 저장 → AUTO 연결 → 달력 적용 → 날짜 조회 전체를 통합 검증
- 일반 REVIEW 무중량 프로그램은 변하지 않는지, 별도 세션과 볼륨일은 유지되는지 검사
- 연결된 실제 날짜, 날짜 이동 시 갱신, 다른 적용 건과 분리, 중복 시퀀스 거절 검사
- 기본 Gate A–I 회귀 및 Android CI 서명 APK 생성

릴리스 브랜치/main 변경 전 실기기 테스트를 별도로 수행해야 한다.
