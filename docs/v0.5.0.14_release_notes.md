# v0.5.0.14 release notes

## Summary

v0.5.0.14 is a focused user-facing quality release. It separates stable
program diagnostics and canonical runtime metadata codes from localized
presentation, then reshapes the affected Compose surfaces for clearer narrow
screen and large-font use.

## Baseline

- Started from latest `origin/main`
  `efb617567cbfea0a36882e06770409b3b1799dc8`.
- Previous app identity: `0.5.0.13 / 500013`.
- Implementation commit:
  `8f78c99b11af14c2715a36532d83256e7ebfe4bf`.

## Program result messages

- Replaced the corrupted selected-main repair sentence with:
  `근력 메인 운동이 보조 운동에 밀리지 않도록 구성을 보정했습니다.`
- Domain and data code now emit typed `ProgramUserNotice` values. Stable
  optimization action codes remain in traces and warnings only.
- Excluded and preferred exercise results preserve their counts while normal
  completion UI resolves concise Korean or English resources.
- Multiple results render as separate severity-labelled items instead of one
  newline-joined diagnostic block.

## Metadata presentation

- Added one field-aware display catalogue with 1,107 registered canonical
  labels in both Korean and English.
- Selector identity, callbacks, Room rows, analysis inputs, program inputs,
  backup and restore continue to use canonical codes.
- Search matches Korean labels, canonical codes, and English labels.
- Existing readable Korean values display unchanged.
- Unknown nonblank values remain selectable and persist unchanged while
  displaying `등록되지 않은 값 · ORIGINAL_CODE`.
- Generated resources come from
  `tools/generate_metadata_display_catalog.py`; translation logic is not
  duplicated across screens.

## UI refinement

- Metadata selectors use label-above-value field surfaces with clear tap
  semantics and full selected values.
- Multi-select chips wrap, show at most three preview values, and communicate
  the remaining count without horizontal scrolling.
- Exercise information is grouped into movement, equipment/muscle, program,
  stress/recovery and badminton-transfer sections; empty sections are omitted.
- Metadata copy displays localized role information.
- Focused Compose tests cover 320dp width, 1.5 font scale, wrapping chips,
  several program notices, grouped information and reachable editor actions.
- No intentional ellipsis is used for selected metadata values or program
  notices.

## Compatibility

- Room database version remains `26`.
- Backup manifest version remains `9`.
- Restore CSV schema remains `8`.
- Program backup schema remains `2`.
- No Room migration, stable-key change, metadata rewrite, backup-format change,
  analysis-classifier change or program-application behavior change is included.

## Verification

- Focused program notice, metadata catalogue, responsive Compose UI, editor,
  persistence, backup/restore and ProgramBuilder tests passed.
- Full `:app:testDebugUnitTest`: 1,106 tests across 191 suites, zero failures,
  errors or skips.
- `:app:compileDebugKotlin` and `:app:compileDebugAndroidTestKotlin`: passed.
- `:app:assembleDebug`: passed; generated a 46,921,619-byte APK with SHA-256
  `1A9CD131A781FF43AF9E1E577BC0B0026D2431FFC489E00B48FD27BF4EDAAB2A`.
- Protocol documentation validation: passed, 8 families and 32 protocols.
- `:app:lintDebug` ran after suppressing whole-app English completeness for the
  existing Korean-only resource file. It fails only on the pre-existing
  unchanged `app/src/main/res/values/themes.xml:5` API 27/minSdk 26 `NewApi`
  issue; 37 non-blocking warnings remain.

## Remaining limits

- This release establishes Korean and English coverage for the affected
  metadata catalogue and program notices; it does not claim full-app English
  localization.
- Existing specialized screens outside this metadata/program-result scope can
  continue to be refined under the same presentation contract.
