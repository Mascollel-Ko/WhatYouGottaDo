# v0.5.0.26 release notes

## Summary

v0.5.0.26 is a presentation-routing release. It connects the existing Korean
and English metadata display catalogue to the authoritative field registry and
routes production exercise metadata UI by fieldKey. Canonical metadata,
analysis, planning, Room, backup, and restore behavior are unchanged.

## Cause

The catalogue already contained reviewed labels and aliases, but 70 production
UI decisions still selected `MetadataDisplayField` domains directly. The
generated field-display contract also assigned catalogue routing to typed or
internal fields and did not explicitly model the three hybrid catalogue/user
text fields. This duplicated routing responsibility and allowed future raw-code
leaks.

## Changes

- Repaired `displayDomain`, `localizationMode`, `valueKind`, and display
  disposition at `ExerciseMetadataFieldPolicyRegistry` source.
- Added explicit hybrid routing for `exercise.category`, `exercise.detail1`,
  and `exercise.detail2`.
- Kept `exercise.archivedAt` semantically unchanged but classified it as
  `NEVER_DISPLAY`; it is not treated as elapsed duration.
- Added the thin `MetadataTranslator` fieldKey facade. It contains no label or
  alias map and delegates all translation content to `MetadataDisplayCatalogue`.
- Routed editor, copy dialog, exercise picker/list/detail/info, exercise filter,
  and program category presentation through field keys.
- Preserved canonical single- and multi-select editor callback values, Korean
  and English aliases, exact hybrid lookup, arbitrary user text, and safe
  unknown-token presentation.
- Kept connective-tissue child names on their reviewed load-unit names instead
  of routing load-unit identifiers through the unrelated tissue-code domain.
  Tissue calculations, states, recovery, and baselines are unchanged.
- Added deterministic routing inventory and coverage validation.

## Boundaries and follow-up

Exercise-name bilingualization, a Home language selector, `values-ko`, and
general UI-string migration are intentionally outside this Phase 1 release.
Compatibility/search-only catalogue rows remain searchable and are not
promoted to production display entries.
