## 원인

이전 근력 수행능력 posterior는 알려진 RPE를 양방향 RIR 확률 관측으로
사용하지 않았고, 약한 lower-bound가 높은 prior 중심을 충분히 교정하지
못할 수 있었습니다. 프록시 운동은 target-specific factor에 직접 영향을 줄
수 있었으며, 운동 자체의 수행 변화와 target 운동의 절대 kg가 분리되지
않았습니다. 또한 runtime 반복 곡선이 검토된 source 범위보다 짧은
1~12회까지만 열려 있었습니다.

## 변경 내용

### RPE/RIR likelihood

- `strength-rpe-rir-policy-1.0.0`을 추가했습니다.
- 알려진 RPE는 가능한 RIR의 discrete probability mixture로 처리합니다.
- RPE 누락은 lower-censored evidence로, confirmed `0 reps / RPE 10`은
  upper-censored failure evidence로 처리합니다.
- RIR 불확실성은 mixture에 한 번만 포함하며 observation variance에 다시
  더하지 않습니다.

성공 세트의 load를 `w`, reps를 `r`, RIR을 `k`, repetition curve를 `q`라
할 때 component 중심은 다음과 같습니다.

`z_k = log(w / q(r + k))`

`L_set(c) = sum_k P(K=k | RPE) Normal(c; z_k, sigma_k^2)`

### 같은 세션과 scalar grid

- 같은 날짜·운동의 세트는 독립 컨디션으로 취급하지 않습니다.
- 공통 session random effect를 15-node Gauss-Hermite로 적분합니다.
- prior와 비정규 likelihood는 deterministic 1,025-point scalar grid에서
  결합하며 경계 질량과 확장 횟수를 진단으로 저장합니다.

`L_session(c) = integral Normal(d; 0, tau_session^2) product_i L_i(c + d) dd`

### Exercise-local posterior와 proxy

- stable key별 exercise-local posterior와 immutable local history를
  추가했습니다.
- 첫 proper observation은 local baseline만 설정합니다.
- 이후 관측은 session likelihood와 local prior 사이의 log innovation을
  계산합니다.
- 검토된 proxy는 절대 kg를 target 운동 kg로 변환하지 않습니다.
- `LOCAL_INNOVATION_SHARED_ONLY` 계약에 따라 shared factor에만 local
  innovation을 전달하고 모든 target-specific loading은 0으로 강제합니다.
- 여러 proxy 신호는 fingerprint 순으로 한 batch update를 수행합니다.

`delta_local = E[log C_session] - E[log C_local_prior]`

`y_proxy = alpha * delta_local`

`H_proxy = alpha * h_shared`
