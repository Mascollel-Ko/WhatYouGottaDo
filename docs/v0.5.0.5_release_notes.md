## 변경

- 메인 근력 분석의 `기존 공식 환산값` Epley card와 전용
  `MainLiftE1rmCard`/`mainLiftE1rmSpec`를 제거했습니다.
- `현재 수행능력 추정`에서 `레벨`과 `성장률`을 선택할 수 있습니다.
- registry 순서의 target을 1~4개 선택하며 최소 한 target을 항상 유지합니다.
  새 선택은 focus가 되고, focused target을 해제하면 첫 remaining target으로
  상세 focus가 이동합니다.
- `레벨`은 공통 kg 축에 target별 posterior 중앙값, 80% band와 직접
  RPE/RIR session observation을 표시합니다. 중량 풀업은 총부하입니다.
- `성장률`은 같은 target의 바로 이전 persisted posterior 중앙값 대비
  변화를 사용합니다. 첫 point는 값이 없고 0%를 만들지 않습니다.
- chart는 target별 날짜 합집합을 사용하고 없는 날짜를 만들지 않습니다.
  proxy local-load 값은 target kg나 성장률 marker에 넣지 않습니다.
- 차트 계약은 기존 single band를 보존하면서 multiple interval band,
  semantic color key, hollow marker와 horizontal reference value를
  지원합니다.

## Lab 공급원

Lab의 기존 `BENCH_PRESS_E1RM`, `SQUAT_E1RM`, `DEADLIFT_E1RM` ID는
호환 키로 유지하지만 표시명과 값은 각 주의 마지막 persisted posterior
중앙값입니다. `StrengthAndMuscleMetricSeriesBuilder`의 Epley series와
`weight * (1 + reps / 30)` 계산은 제거했습니다.

Epley 계산은 이번 canonical performance UI/Lab 공급원 밖의 별도 책임인
strength index, fatigue intensity, program weight suggestion, exercise
analysis 및 legacy proxy experiment에는 남아 있습니다. 이들의 계산은 이번
작업에서 변경하지 않았습니다.

## 성장률 계약

`growthRatePercent = ((currentPosteriorMedian / previousPosteriorMedian) - 1) * 100`

현재 interval은 이전 중앙값 대비 low/high를 각각 변환한 설명용 범위이며,
두 시점 ratio의 정확한 posterior distribution이라고 주장하지 않습니다.

## 보존

posterior 계산, RPE/RIR likelihood, repetition curves, proxy transfer,
persisted history, rebuild lifecycle, raw workout data와 Room schema는
변경하지 않았습니다.
