# WhatYouGottaDo Documentation

Current documentation is intentionally limited to material used by the current
application, tests, tooling, and protocol registry.

- `docs/protocols/`: canonical product protocols and their registry.
- `docs/metadata_authority/`: current metadata authority and closeout material.
- `docs/audits/`: audits referenced by current contracts or validation.
- `docs/analysis_method_reviews/`: current analysis review templates.
- `docs/reviews/`: reviewed copy required by current contract tests.
- `docs/v0.5.0.26_release_notes.md`: release notes for the current version.
- `docs/codex_worklog.md`: cumulative implementation worklog.

Older release notes, handoffs, superseded designs, and generated Markdown
reports were removed from the working tree. They remain recoverable from Git
history. Start with the [Protocol Library](protocols/README.md) when checking
current behavior.
