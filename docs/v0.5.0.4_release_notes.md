# v0.5.0.4 근력 분석 파생 상태 재구축 보정

## 기준

- 시작 commit: `0f8840a2f2eca9b40907d5f3f12f60b028b81145`
- 이전 앱 버전: `0.5.0.3 / 500003`
- 릴리스 앱 버전: `0.5.0.4 / 500004`
- Room: `23` 유지, schema 변경 없음

## 원인

v0.5.0.3 이전의 근력 파생 결과가 current correction 실패 뒤에도 legacy
ACTIVE revision으로 남아 분석 화면에 표시될 수 있었다. 실패 상태는 이후
startup에서 영구적으로 재시도되지 않을 수 있었고, summary는 필요한 current
revision이 아니라 임의의 ACTIVE revision을 읽었다.

## 변경

- `strength-derived-state-0.5.0.4`를 current revision fingerprint에 포함했다.
- 저장된 파생 상태가 current model, registry, RIR, curve, derived-state
  fingerprint와 호환되지 않을 때만 한 번 전체 재구축한다.
- 호환 가능한 current ACTIVE revision은 일반 startup이나 분석 화면 진입에서
  재생하지 않는다. completion marker가 없으면 기존 행을 유지하고 marker만
  복구한다.
- 재구축 시 다음 파생 테이블만 비운다:
  `strength_posterior_events`, `strength_posterior_history`,
  `strength_posterior_model_state`, `strength_curve_posteriors`,
  `strength_posterior_evidence`, `strength_model_revisions`,
  `strength_exercise_performance_state`,
  `strength_exercise_performance_history`,
  `strength_proxy_transfer_history`.
- 완료 workout date를 날짜순으로 current v3 모델에 재생하고 모든 event가
  `PROCESSED`인 경우에만 current revision을 `ACTIVE`로 승격한다.
- 성공 marker는
  `strength_derived_reset_rebuild_0_5_0_4_complete`이며 전체 성공 뒤에만
  기록한다.
- 실패하면 legacy fallback 없이 current revision을 `FAILED`로 남기고 다음
  startup에서 파생 상태를 다시 비운 뒤 재시도한다.
- 성공 이후 일반 workout 완료는 새 event/history만 append하며 이전
  same-model snapshot을 다시 쓰지 않는다.
- 백업 복원은 원시 기록을 복원한 뒤 백업의 strength derived row를 폐기하고
  current canonical 모델로 명시적 재구축한다.
- 분석 summary는 `strength-revision-3.0.0`의 compatible ACTIVE row만 읽는다.
  재구축 중에는 `현재 근력 분석 모델로 과거 운동 기록을 재계산하고 있습니다.`,
  실패 시에는 `현재 근력 분석을 재계산하지 못했습니다.`와 진단 코드를
  표시하며 수치 카드와 chart를 숨긴다.

## 보존

다음 원시 사용자 데이터는 correction 대상이 아니다: exercises/stable keys,
workout entries/sets, confirmed state, load, repetitions, RPE, performed date,
bodyweight, daily metrics/check-ins, initial profile, notes, runtime metadata,
programs/plans 및 unrelated analysis data.

Bayesian model `strength-performance-model-3.0.0`, RPE/RIR policy
`strength-rpe-rir-policy-1.0.0`, repetition curves
`repetition-curve-assets-2.0.0`, exercise-local posterior와 shared-only proxy
계산식은 변경하지 않았다.
