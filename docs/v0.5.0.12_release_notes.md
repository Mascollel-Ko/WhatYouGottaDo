# v0.5.0.12 Release Notes

## Purpose

v0.5.0.12 lets a selected calendar record range become an exact reusable
training program and preserves heterogeneous set prescriptions through edit,
application, backup and restore.

## Record Range Conversion

- The selected inclusive span is preserved exactly; the first selected date
  maps to week 1 Monday and blank dates remain blank.
- Confirmed and planned source sets are copied as prescriptions without
  modifying the original workout history.
- Duplicate exercise rows remain separate and keep their stable order.
- Reps, weight and timed sets are copied set by set.
- Applied program sets are new planned, unconfirmed workout sets.

## Program Persistence And UI

- Room 26 adds `training_program_item_sets`.
- Child set rows are authoritative when present. Existing scalar program items
  remain readable through one legacy fallback resolver.
- The program editor supports heterogeneous set rows.
- Program Open shows compact read-only exercise cards, exact set lines and the
  existing exercise information dialog. Empty days are not rendered.

## Backup Compatibility

- Backup format 9 and program schema 2 add authoritative `program_item_set`
  rows to the existing full program snapshot.
- Export, preflight, canonicalization and transactional restore cover the
  child graph and reject orphan, duplicate or malformed set rows.
- Restore CSV schema remains 8. Older program schema 1 backups and scalar
  programs remain readable.
- The normal repository backup export/import path is covered by regression
  tests; the format was not split into a second backup path.
