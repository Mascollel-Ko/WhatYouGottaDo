# v0.5.0.30 release notes

## Summary

v0.5.0.30 is a presentation, localization, and adaptive-layout hotfix. It
closes remaining English runtime semantic leaks, wraps compact controls as
whole items on narrow screens, and makes daily/weekly axis tick density depend
on measured label width without changing chart data.

## Baseline and boundaries

- Started from `origin/main` / v0.5.0.29 at
  `705a37e625e86219e98ae7fcac82ee109b2dd6a6`.
- Version changed from `0.5.0.29 / 500029` to `0.5.0.30 / 500030`.
- Room remains 29, backup format remains 12, and restore schema remains 11.
- Time-series execution remains
  `AnalysisScreen -> TrainingViewModel -> TimeSeriesAnalysisCoordinator ->
  TimeSeriesAnalysisService -> compatibility analyzer -> typed state ->
  AnalysisLabUi`.
- No estimator, numeric fixture, metadata identity, persistence, ProgramBuilder,
  fatigue, tissue, strength posterior, or user-data behavior changed.

## Changes

### Adaptive compact controls

- Initial-profile single and multi choice groups now use content-aware
  `FlowRow` layout instead of fixed item chunks.
- Exercise category filters and management actions wrap whole controls instead
  of horizontally clipping or vertically fragmenting labels.
- Record date navigation gives the date its own row and keeps previous, next,
  and calendar actions readable at narrow widths.
- Compact labels stay on one line; normal paragraphs continue to wrap.

### Width-aware temporal axes

- Every formatted date label is measured with the active Compose text style,
  density, locale, and font scale.
- Wide charts retain all ticks. When labels collide, the visual stride grows
  from approximately two-week spacing until measured bounds fit.
- First/final and month-transition ticks are preferred only when they remain
  collision-free.
- Plotted points, bars, date domains, real temporal gaps, and full accessibility
  descriptions are unchanged.

### English runtime presentation

- Dynamic templates localize approved semantic arguments before final sentence
  formatting, preventing English prefixes with Korean fatigue, axis, metadata,
  or status suffixes.
- Data-transfer operation, status, stage, and section headings use presentation
  localization while raw diagnostic exports remain available separately.
- User-authored Korean text remains exact pass-through content.
- The malformed record labels `0candle` and `Huh120` were traced to authority
  rows for `초` and `휴${}` and corrected to `0sec`/`Rest 120` presentation.
- The missing exercise-management `Unhide` translation was added.
- Authority generation now normalizes embedded CSV line endings so Windows and
  CI stale checks compare the same deterministic output.
