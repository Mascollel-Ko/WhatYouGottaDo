# v0.5.0.27 release notes

## Summary

v0.5.0.27 completes the approved Korean/English localization of the production
app. It preserves system-driven initial locale behavior, adds a compact Home
selector, applies deterministic English presentation to runtime UI, built-in
exercise names, metadata, connective-tissue education, dates, units, errors,
and accessibility text, and leaves product calculations and persistence
unchanged.

## Baseline and preserved local work

- Origin baseline: `5eecdac1d3dc87fe5a8982221b891345a8794710`
  (`v0.5.0.26`).
- Preserved cleanup: `ad4fbf378cb4032b3d2291faeb0946a7ec2bd1b3`.
- The cleanup's 225 obsolete Markdown deletions were retained; old documents
  were not restored.
- Effective implementation branch includes localization audit, authority,
  locale foundation, stable-identity presentation, and runtime routing
  checkpoints through `ed3b265bd6128099526f6737e590f15b294e126b`.

## Changes

- Imported the byte-identical approved v2 workbook and deterministic generator.
- Replaced the stale missing-approval gate with current-baseline route,
  placeholder, semantic, and Korean-leak validation.
- Kept empty application locale override as follow-system; added explicit
  `한국어` / `English` Home choices without a third System button.
- Routed production text through generated exact/dynamic presentation while
  retaining Korean base resources and English `values-en` resources.
- Localized all 257 built-in/history exercise identities by stableKey and kept
  custom names verbatim.
- Reused metadata catalogue/translator and tissue stable-identity overlays.
- Added active-locale dates, contextual units/plurals, and TalkBack text.

  only those two application locales are declared in this release.

  authority rows, not KO/EN domain branching.
