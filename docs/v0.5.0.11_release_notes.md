# v0.5.0.11 Release Notes

## Purpose

v0.5.0.11 preserves restored user-edited exercise metadata and pre-fills a
new manual workout plan from the latest confirmed set for the same exercise.

## Backup Restore Fix

- Restore now reuses an already restored Exercise by exact stableKey without
  reapplying built-in seed metadata while importing WorkoutSet rows.
- A restored runtime metadata override therefore protects the matching
  user-edited Exercise name, category, target muscles and other persisted
  metadata through set import, later seeding and repeated restore.
- Canonical seed resolution remains the fallback only when the exercise does
  not already exist. No display-name, fuzzy or equipment inference was added.

## Manual Plan Prefill

- Adding an exercise manually on the Record screen creates exactly one fresh,
  unconfirmed planned set.
- It copies only `reps`, `weightKg` and `manualWeight` from the latest
  confirmed set for the same exact stableKey at or before the target date.
- The lookup is deterministic by workout date, performance timestamp, entry
  ID, set index and set ID.
- Future records, unconfirmed sets and same-name exercises with another
  stableKey are ignored.
- With no confirmed history, the existing zero-value planned-set defaults
  remain unchanged.
- Program application, date copy/move, import/restore and the existing
  add-set action are unchanged.

## Analysis Boundary

The pre-filled set remains unconfirmed. It is therefore not counted as
fatigue load or strength-posterior evidence until the user confirms it.
