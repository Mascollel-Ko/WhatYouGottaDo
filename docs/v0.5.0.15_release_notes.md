# v0.5.0.15 release notes

## Summary

v0.5.0.15 is a narrow startup migration hotfix. It fixes an invalid SQL value
list in the existing Room 24-to-25 exercise stable-key migration.

## Cause

The unresolved-exercise placeholder INSERT declared 67 columns but supplied 69
values. Databases upgrading through version 24 therefore failed during startup
with `SQLiteException: 69 values for 67 columns`, and Android closed the app.

## Change

- Removed the two excess placeholder values so all 67 values align with the 67
  declared exercise columns.
- Extended the existing Room migration regression test to verify the unresolved
  placeholder's confidence, active, custom and review fields.
- Kept Room at version 26 and did not change exported schemas, exercise
  identities, backup formats, user records or current-database behavior.

## Verification

- `:app:testDebugUnitTest`: 1,106 tests across 191 suites, zero failures,
  errors or skips.
- `:app:compileDebugAndroidTestKotlin`: passed.
- `:app:assembleDebug`: passed; generated a 46,921,615-byte APK with SHA-256
  `B3D87A5DF773895B019F53676302DFF2E6EA8073A178721AF4EB72DE1CEF4747`.
- Protocol documentation validation: passed, 8 families and 32 protocols.
- The focused Room migration instrumentation test passes the corrected INSERT,

- A patched APK was installed with `adb install -r` over the original crashing

  the app process remained alive, and the Android crash buffer stayed empty.
