# v0.5.0.9 Release Notes

## Purpose

v0.5.0.9 restores the Android debug build pipeline after the v0.5.0.8
legacy-restore hotfix.

## Cause

The v0.5.0.8 exercise identity document declared protocol version 1.0.1, but
the canonical registry and protocol index still declared 1.0.0 and the prior
audit commit. Canonical protocol validation therefore stopped GitHub Actions
before unit tests and APK assembly.

## Changes

- Aligned `DATA-EXERCISE-IDENTITY` registry, document and index metadata.
- Registered the focused backup/restore behavior test and v0.5.0.8 release note
  as protocol anchors.
- Bumped the app to `0.5.0.9 / 500009`.

## Behavior

The v0.5.0.8 legacy direct mappings and deleted generic one-arm-row handling
are unchanged. No backup schema, Room schema, exercise metadata or runtime
mapping behavior changed.

## Validation

- Canonical protocol documentation validation passed: 8 families and 32
  protocols.
- Full debug unit tests passed: 1,064 tests and zero failures.
- `:app:assembleDebug` passed and produced `app-debug.apk`.
